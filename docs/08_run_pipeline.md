# Запуск пайплайна

Основной файл:

```text
src/pipeline/run_pipeline_orangepi.py
```

## Что нужно перед запуском

В рабочей папке должны быть:

```text
label_detector_fp16.rknn
label_defects_detector_fp16.rknn
```

Также должен быть установлен `rknn-lite2`.

## Запуск на видео

Откройте `src/pipeline/run_pipeline_orangepi.py` и проверьте:

```python
SOURCE_PATH = "path/to/video.mp4"
LABEL_MODEL_PATH = "label_detector_fp16.rknn"
DEFECT_MODEL_PATH = "label_defects_detector_fp16.rknn"
```

После этого:

```bash
python3 src/pipeline/run_pipeline_orangepi.py
```

## Запуск с камеры

Если используется `/dev/video0`, в коде можно указать:

```python
SOURCE_PATH = "0"
```

И запустить:

```bash
python3 src/pipeline/run_pipeline_orangepi.py
```

Если OpenCV не открывает камеру, сначала проверьте ее через команды из `docs/07_camera_capture.md`.

## Что сохраняет пайплайн

Пайплайн может сохранять:

- кадры с отрисованными box;
- crop этикеток;
- CSV по кадрам;
- CSV по трекам;
- итоговое видео.

Точный набор выходных файлов зависит от настроек внутри `run_pipeline_orangepi.py`.

## Как принимается решение о браке

1. Модель поиска этикетки находит ROI.
2. ROI фильтруется по площади, отступам, резкости и контрасту.
3. Вторая модель ищет элементы маркировки.
4. Функция `decide_defective` принимает решение по количеству найденных элементов.
5. Для видео используется агрегация по треку, чтобы решение не зависело от одного случайного кадра.

## Отладка

Если ничего не находится:

- проверьте, что модель соответствует задаче;
- уменьшите threshold;
- проверьте размер входа модели;
- проверьте, что кадр читается;
- сохраните один кадр и прогоните его отдельно.

Если все считается браком:

- проверьте порядок классов;
- проверьте thresholds второй модели;
- проверьте функцию `decide_defective`;
- визуально посмотрите crop, который получает вторая модель.

Если пайплайн медленный:

- включите пропуск кадров;
- уменьшите входной размер модели;
- сохраняйте меньше отладочных изображений;
- используйте ROI;
- проверьте, что реально используется RKNN/NPU, а не CPU-версия.
