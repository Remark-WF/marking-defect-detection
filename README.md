# Система контроля качества маркировки

Репозиторий содержит техническую часть дипломного проекта: обучение моделей YOLO, конвертацию весов в ONNX/RKNN и запуск пайплайна контроля маркировки на Orange Pi 5.

Задача проекта - автоматически находить этикетку на кадре, проверять наличие ключевых элементов маркировки и помечать объект как исправный или дефектный.

## Архитектура

Пайплайн состоит из двух моделей:

1. `label_detector` - находит этикетку на полном кадре.
2. `label_defects_detector` - анализирует crop этикетки и ищет элементы:
   - `anchor_icon`
   - `anchor_lot`
   - `anchor_volume`
   - `target_field`

После детекции применяется простая логика контроля: если ожидаемые элементы не найдены в нужном количестве, маркировка считается дефектной. В версии для Orange Pi дополнительно есть трекинг этикеток и агрегация решения по нескольким кадрам.

## Что лежит в репозитории

```text

scripts/              Вспомогательные команды для запуска и камеры
src/collector/        Сбор видео с камеры на Orange Pi

src/ui/               Панель оператора

```

## Где хранятся большие файлы

Веса, датасеты, видео и результаты обучения не хранятся в Git. Их нужно положить во внешнее хранилище: Google Drive, Яндекс Диск, облако университета или другой общий ресурс.

Рекомендуемая структура внешней папки:

```text
marking-defect-assets/
  datasets/
    label_dataset.zip
    defect_dataset.zip
    test_videos.zip
  weights/
    pt/
    onnx/
    rknn/
  results/
    label_metrics.zip
    defect_metrics.zip
    inference_examples.zip
  docs/
    diploma.pdf
    presentation.pdf
```

## Быстрый старт

1. Скачайте внешние файлы по ссылке выше.
2. Распакуйте датасеты и веса рядом с репозиторием или в удобную рабочую папку.
3. Настройте Python-окружение:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

На Windows:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
py -3 -m pip install -r requirements-dev.txt
```

4. Для обучения используйте инструкции:
   - [Обучение модели поиска этикетки](docs/03_train_label_detector.md)
   - [Обучение модели элементов маркировки](docs/04_train_defect_detector.md)

5. Для экспорта весов:
   - [Конвертация весов PT -> ONNX -> RKNN](docs/05_export_weights.md)

6. Для запуска на Orange Pi 5:
   - [Настройка Orange Pi 5](docs/06_orangepi5_setup.md)
   - [Полезные команды для камеры](docs/07_camera_capture.md)
   - [Запуск пайплайна](docs/08_run_pipeline.md)

## Проверенные результаты

По сохраненным результатам обучения:

| Модель | Задача | mAP50 | mAP50-95 | Precision | Recall |
|---|---|---:|---:|---:|---:|
| YOLOv5n | Поиск этикетки | 0.9651 | 0.95437 | 0.9989 | 0.96226 |
| YOLOv8n | Элементы маркировки | 0.995 | 0.86786 | 0.99577 | 1.0 |

Эти значения нужно воспринимать как результаты на текущем датасете проекта. При расширении датасета метрики нужно пересчитать.

## Основной порядок работы

1. Собрать или обновить видео.
2. Нарезать кадры и разметить датасеты.
3. Обучить `label_detector`.
4. Вырезать crop этикеток и разметить элементы маркировки.
5. Обучить `label_defects_detector`.
6. Экспортировать веса в ONNX.
7. Конвертировать ONNX в RKNN FP16 для RK3588.
8. Скопировать `.rknn` на Orange Pi 5.
9. Запустить пайплайн и проверить результаты на тестовых видео.
