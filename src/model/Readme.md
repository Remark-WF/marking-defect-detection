# Модели

Первая модель в этом проекте решает задачу **обнаружения этикеток** на изображениях, снятых с производственных линий. С помощью этой модели можно автоматически находить расположение этикеток на различных продуктах или упаковках.

В будущем мы планируем обучить дополнительные модели, например, для **обнаружения брака** на тех же изображениях, что будет полезно для автоматической проверки качества продукции.

## Доступ к модели

Обученная модель для задачи **обнаружения этикеток** доступна для скачивания по следующей ссылке:

- [Скачать модель для обнаружения этикеток](https://drive.google.com/drive/folders/1krBXMVql8i6iG1usUbNdDRefAG4jx9z-)

### Как использовать модель

1. Перейдите по указанной ссылке.
2. Скачайте файл с моделью (например, `best.pt`).
3. Используйте модель в вашем проекте или интегрируйте её в вашу систему для инференса.
