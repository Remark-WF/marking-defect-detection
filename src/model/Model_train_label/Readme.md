# Модели

Первая модель в этом проекте решает задачу **обнаружения этикеток** на изображениях, снятых с производственных линий. С помощью этой модели можно автоматически находить расположение этикеток на различных продуктах или упаковках.

В будущем мы планируем обучить дополнительные модели, например, для **обнаружения брака** на тех же изображениях, что будет полезно для автоматической проверки качества продукции.

## Запуск обучения

Для того чтобы обучить модель на вашем датасете, используйте скрипт `train_label_model.py`. Вот как это сделать:

### 1. Подготовьте данные

Создайте файл `data.yaml`, который будет описывать ваши данные. Пример:

```yaml
path: "dataset"  # Путь к директории с изображениями
train: "images/train"  # Папка с изображениями для обучения
val: "images/val"  # Папка с изображениями для валидации
names:
  0: "Этикетка"  # Название класса
```
### 2. Запустите обучение
```bash
python src/model/train_label_model.py --data "path/to/data.yaml" --epochs 50 --img_size 960 --batch 8 --device "cuda:0"
```
--data: Путь к вашему файлу data.yaml.
--epochs: Количество эпох для обучения модели.
--img_size: Размер изображений, которые будут использоваться для обучения.
--batch: Размер пакета (batch size).
--device: Устройство для обучения (например, cuda:0 для GPU или cpu для использования процессора).

### 3. Результаты обучения

После завершения обучения, лучшая модель будет сохранена в папке:
```
runs/detect/train_labels/weights/best.pt
```
